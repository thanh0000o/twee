# Guestbook smileys

- Glossy moods, Messenger figures, jelly faces, pixel faces and XP avatars are
  cropped from the five reference sheets supplied by the website owner.
- The additional Tango faces are original Tango Desktop Project icons (2007),
  released into the public domain, downloaded from Wikimedia Commons:
  https://commons.wikimedia.org/wiki/File:Face-smile.svg
  https://commons.wikimedia.org/wiki/File:Face-wink.svg
  https://commons.wikimedia.org/wiki/File:Face-surprise.svg
  https://commons.wikimedia.org/wiki/File:Face-sad.svg
  https://commons.wikimedia.org/wiki/File:Face-cool.svg
  Original project mirror (used for the glasses/cool face and repeat preparation):
  https://github.com/Distrotech/tango-icon-theme/tree/master/32x32/emotes

Preparation: `scripts/assets/prepare-guestbook-smileys.py`.
All icons are served locally and displayed as small static inline images.
