# {thành lambeets}

my little corner of the internet → [thanhlambeetstwee.com](https://thanhlambeetstwee.com)

A personal website where I keep my ideas and the things I make while figuring them out. It's inspired by early-2000s web design and [Neocities](https://neocities.org/): glossy spheres, curly brackets, colour themes you can switch, and little details to find while you look around.

## what's on it

- **{works}** projects, from student work to small AI tools
- **{artwork}** digital art and video pieces
- **{visualisations}** photos I edited
- **{music}** my record collection, straight from Discogs
- **{blog}** site updates, opinion pieces and favourite links
- **{guestbook}** leave a hello :-)

## made with

React and Vite for the site, a small Express API for the guestbook, visitor counter and records, and Postgres (Neon) to keep everything. It runs on Vercel.

## run it yourself

```bash
pnpm install
cd artifacts/gerrit-thanh-landing
pnpm run dev
```

The guestbook and music pages need a `DATABASE_URL` and a `DISCOGS_TOKEN`. Without them, the rest of the site still works.
